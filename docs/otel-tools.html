Log Shippers & Forwarders

Tools dedicated to collecting and routing log data — often deployed before the OTEL Collector, or in place of the filelog receiver

Tool Primary Role OTLP Output Footprint K8s Default License
Fluent Bit Lightweight log collector & forwarder ✅ Yes ~1 MB binary / ~10 MB RAM ✅ Pre-installed (EKS, GKE, AKS) Apache 2.0
Fluentd Log aggregator & router (EFK stack) ✅ Yes (plugin) ~40 MB (Ruby runtime) ⚠️ Common, being replaced by Fluent Bit Apache 2.0
Logstash Log processing pipeline (ELK stack) ✅ Yes (output plugin) ~500 MB (JVM) ❌ No Elastic License
Vector High-performance log & metrics router ✅ Yes (OTLP sink) ~30 MB (Rust) ❌ No MPL 2.0
OTEL Collector Unified traces + metrics + logs pipeline ✅ Native ~50–100 MB ⚠️ Needs Operator Apache 2.0
Fluent Bit → OTEL Collector hybrid pattern (common in Kubernetes)
┌─────────────┐     per node DaemonSet
│  Pod logs   │
└──────┬──────┘
       │ collected by
       ▼
[ Fluent Bit ]  ← ~10 MB RAM, already present in most clusters
       │ OTLP output
       ▼
[ OTEL Collector gateway ]  ← sampling, enrichment, fan-out
       │              │
       ▼              ▼
[ Datadog ]    [ SigNoz / Loki ]

If your cluster already has Fluent Bit running, don't replace it — add an OTLP output plugin and point it at an OTEL Collector. The Collector handles routing, sampling, and backend fan-out.

Quick Pick Guide
Need Recommended picks
Fully open source, self-hosted, all signals SigNoz (all-in-one) — or — Grafana OSS stack (Tempo + Prometheus + Loki + Grafana)
Best trace query UX Honeycomb (BubbleUp), Tempo + TraceQL, or SigNoz
Best metrics ecosystem Prometheus + Grafana (OSS) or Grafana Cloud
Broadest integrations, enterprise scale Datadog or Dynatrace
Most affordable SaaS at high ingest volume Grafana Cloud, Coralogix, or Axiom
High-cardinality trace debugging Honeycomb
