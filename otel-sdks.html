How to set up OTEL instrumentation in the four most common server-side languages — from zero-code auto-instrumentation to manual span creation.

SDK Architecture — Shared Concepts

Every OTEL SDK — regardless of language — implements the same layered architecture. The API and SDK are separate packages; libraries instrument against the API, your app wires up the SDK.

Your Application Code
Calls tracer.start_span(), meter.create_counter(), etc.
↓ calls
OTEL API
Stable, minimal interface. No-ops if no SDK is registered.
↓ delegates to
OTEL SDK
Samplers · Span processors · Metric aggregators
↓ flushes to
Exporter (OTLP)
Sends to Collector or backend over gRPC/HTTP

Python

opentelemetry-sdk · opentelemetry-instrument CLI · auto-instrumentation packages

Zero-Code Auto-Instrumentation

pip install opentelemetry-distro opentelemetry-exporter-otlp-proto-grpc
opentelemetry-bootstrap --action=install
# Wrap any Python process — no code changes
opentelemetry-instrument \
  --service-name my-service \
  --exporter-otlp-endpoint http://localhost:4317 \
  python app.py

Node.js

@opentelemetry/sdk-node · auto-instrumentations-node · CJS and ESM support

Zero-Code (CJS)

# No code changes — require the register script before app loads
OTEL_SERVICE_NAME=my-service \
OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4317 \
node --require @opentelemetry/auto-instrumentations-node/register app.js

SDK Setup (tracing.js)

const { NodeSDK } = require('@opentelemetry/sdk-node');
const { OTLPTraceExporter } = require('@opentelemetry/exporter-trace-otlp-grpc');

const sdk = new NodeSDK({
  traceExporter: new OTLPTraceExporter({ url: 'http://localhost:4317' }),
  instrumentations: [getNodeAutoInstrumentations()],
});
sdk.start();
process.on('SIGTERM', () => sdk.shutdown().then(() => process.exit(0)));

Manual Span

const tracer = trace.getTracer('order-service');

async function processOrder(orderId) {
  return tracer.startActiveSpan('process-order', async (span) => {
    span.setAttribute('order.id', orderId);
    try {
      return await doWork(orderId);
    } catch (err) {
      span.setStatus({ code: SpanStatusCode.ERROR });
      span.recordException(err);
      throw err;
    } finally { span.end(); }
  });
}
Go

Go

go.opentelemetry.io/otel · Manual spans · contrib instrumentation packages

Note: Go has no zero-code auto-instrumentation. All spans are added manually or via per-library contrib packages under go.opentelemetry.io/contrib/.

SDK Initialisation

exporter, _ := otlptracegrpc.New(ctx,
    otlptracegrpc.WithEndpoint("localhost:4317"),
    otlptracegrpc.WithInsecure(),
)
res := resource.NewWithAttributes(semconv.SchemaURL,
    semconv.ServiceName("order-service"),
)
tp := sdktrace.NewTracerProvider(
    sdktrace.WithBatcher(exporter),
    sdktrace.WithResource(res),
)
otel.SetTracerProvider(tp)
defer tp.Shutdown(ctx)

Manual Span

tracer := otel.Tracer("order-service")

func processOrder(ctx context.Context, orderID string) error {
    ctx, span := tracer.Start(ctx, "process-order")
    defer span.End()

    span.SetAttributes(attribute.String("order.id", orderID))
    if err := doWork(ctx, orderID); err != nil {
        span.RecordError(err)
        span.SetStatus(codes.Error, err.Error())
        return err
    }
    return nil
}

Java

opentelemetry-javaagent.jar · -javaagent flag · Spring Boot native config

Zero-Code via Java Agent

# Download once
curl -L https://github.com/open-telemetry/opentelemetry-java-instrumentation/releases/latest/download/opentelemetry-javaagent.jar \
     -o opentelemetry-javaagent.jar

# Run — instruments the entire JVM
java \
  -javaagent:opentelemetry-javaagent.jar \
  -DOTEL_SERVICE_NAME=order-service \
  -DOTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4317 \
  -jar myapp.jar

Spring Boot (application.properties)

otel.service.name=order-service
otel.exporter.otlp.endpoint=http://localhost:4317
otel.traces.sampler=parentbased_traceidratio
otel.traces.sampler.arg=0.1

Manual Span (SDK)

Tracer tracer = GlobalOpenTelemetry.getTracer("order-service");

Span span = tracer.spanBuilder("processOrder")
    .setAttribute("order.id", orderId)
    .startSpan();

try (var scope = span.makeCurrent()) {
    processOrder(orderId);
} catch (Exception e) {
    span.recordException(e);
    span.setStatus(StatusCode.ERROR, e.getMessage());
    throw e;
} finally { span.end(); }
